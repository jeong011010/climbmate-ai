## 🎯 핵심 기술 스택 요약 (피그마용)

### Layer 1: Frontend
- **Framework**: React 19.1.1
- **빌드**: Vite 7.1.7
- **스타일**: TailwindCSS 3.4.18
- **HTTP**: Axios 1.12.2
- **라우팅**: React Router DOM 7.9.4
- **PWA**: vite-plugin-pwa 1.1.0
- **브라우저 AI**: TensorFlow.js 4.17.0, ONNX Runtime Web 1.23.0

### Layer 2: Infrastructure
- **컨테이너**: Docker & Docker Compose
- **웹서버**: Nginx (리버스 프록시)
- **SSL**: Certbot / Let's Encrypt
- **작업 큐**: Redis 7-alpine
- **비동기 처리**: Celery 5.3.0

### Layer 3: Backend API
- **Framework**: FastAPI 0.119.0
- **서버**: Uvicorn 0.37.0
- **언어**: Python 3.13
- **이미지 처리**: OpenCV 4.11.0+, Pillow 10.4.0+
- **수치 연산**: NumPy 1.26.4+

### Layer 4: AI/ML Models

#### 홀드 감지
- **모델**: YOLOv8-seg (Ultralytics 8.2.103)
- **백엔드**: PyTorch
- **정확도**: 95%+
- **속도**: ~100ms

#### 색상 분류 (★ 변경됨)
- **방법**: 규칙기반 + ML 하이브리드

## 🔗 주요 연관 관계 매핑

### 1. 사용자 → 결과
```
사용자 업로드
  → Nginx
  → FastAPI
  → YOLO (홀드 감지)
  → 규칙+ML (색상 분류)
  → 하이브리드 (난이도 분석)
  → DB 저장
  → React 렌더링
```

### 2. 피드백 → 학습
```
사용자 피드백
  → SQLite 저장
  → ML 재학습 (scikit-learn)
  → 모델 업데이트
  → 다음 분석에 적용
```

### 3. 색상 분류 흐름
```
홀드 이미지
  ↓
HSV 변환
  ↓
규칙기반 분석 (color_ranges.json)
  ↓
ML 모델 검증 (color_model.pkl)
  ↓
최종 색상 결정
```

### 4. 난이도 분석 흐름
```
홀드 통계 계산
  ↓
ML 모델 시도 (데이터 충분 시)
  ↓ (실패 시)
GPT-4 Vision 호출 (API 키 있으면)
  ↓ (실패 시)
규칙기반 분석 (백업)
  ↓
최종 난이도 출력
```
